# v1.3.2 Enemy Readability Hotfix

Patch release rule: preserve the v1.3.1 permanent UI/UX geometry. This update changes only temporal combat presentation.

Changes:
- Player action resolve and enemy action are separated by a longer read window.
- Enemy action name callout appears before impact.
- Enemy attack_prep pose is shown before damage application.
- Single-target enemy attacks pulse the actual target monster.
- AOE attacks show ALL TARGET during the enemy-read phase.
- Random three-hit attacks show RANDOM x3 during the enemy-read phase.
- Enemy impact is delayed into its own beat.
- Next-turn transition waits until the impact read window has finished.
- BGM/SE pipeline from v1.3.1 is preserved unchanged.
- Reduced-motion and MOTION OFF remain supported.
